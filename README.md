## ⌨️ 사용자의 키워드로 주제를 나누는 Agent, 본문을 작성하는 Agent와 주제와 본문 내용을 기반으로 뉴스 레터를 편집 및 작성하는 Agent

1. 사용자의 입력에 맞는 주제를 분석하고 많은 양의 뉴스를 조사한 기반으로 여러개의 세부 주제 설정 
2. 여러개의 세부 주제에 대한 뉴스 본문 검색을 실시
- 세부 주제가 많을 경우를 대비하여 뉴스 본문 검색은 **비동기적**으로 실시
3. 세부 주제의 본문으로 생성된 내용을 뉴스 레터 편집 및 작성

## 🛠️ 사용 기술 및 라이브러리

- LangChain, LangGraph, OpenAI
- Streamlit

## 📖 상세 내용
- 주어진 키워드를 대주제, 부주제를 나누어 자동으로 뉴스레터를 작성해주는 LLM 시스템
1. search_news
> 사용자의 입력에 대한 뉴스 검색 노드
2. generate_theme
> 검색된 뉴스 제목을 기반으로 대주제와 소주제 생성 노드
3. wrtie_section_num
> **write_newsletter_section_async** 함수를 기반으로 비동기적으 소주제에 대한 뉴스 본문을 작성 ****
4. aggregate
> 작성된 결과물을 통합하는 노드, 대주제 \n 소주제 \n 내용 형식으로 답변
5. editor
> 통합된 결과물을 뉴스 레터 형식에 부합하도록 편집하는 노드
